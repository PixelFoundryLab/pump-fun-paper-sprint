First-Trade Sniper is a pump.fun paper-trading bot for the agent-fun/replay/v2 harness. It buys clean new launches at their first trade — small creator buy, almost no other buyers yet — and sells within a few slots on a small take-profit, a stop loss, or a hard time limit.

## Run it

```sh
node main.ts
```

The bot speaks the replay protocol on stdin/stdout: it reads hello/batch/done lines and writes one reply per batch. Run it through the kit's grader with `node cli/makefun.mjs grade-local --kit . --bot <this repo> --driver process`.
